> Repositório dedicado à documentação, códigos e atividades desenvolvidas ao longo da graduação em Engenharia de Software no CEUB.

# 📖 Sobre o Repositório

Este espaço foi criado com o objetivo de registrar minha evolução acadêmica e técnica como estudante de Engenharia de Software. Aqui você encontrará desde os primeiros algoritmos desenvolvidos nas disciplinas introdutórias até projetos mais complexos de arquitetura de software, banco de dados e desenvolvimento de interfaces.

Cada diretório deste repositório representa um semestre ou uma disciplina específica, contendo seus respectivos projetos, códigos-fonte e documentações.
