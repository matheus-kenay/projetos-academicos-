# Programação Orientada a Objetos

## Sobre

Esta pasta reúne três arquivos Python identificados como PP1 a PP3, desenvolvidos no contexto de estudos de Programação Orientada a Objetos.

## Arquivos

- `PP1.py`
- `PP2.py`
- `PP3.py`

## Tecnologias

- Python 3
- Terminal / PowerShell para execução
- Git e GitHub para controle de versão e armazenamento do código

## Como executar

Com Python 3 instalado, abra um terminal na raiz do repositório e execute, por exemplo:

```powershell
python "Programação Orientada a Objetos/PP1.py"
```

Substitua `PP1.py` pelo exercício desejado. Alguns programas podem solicitar entradas no terminal.

## Objetivo da seção

Organizar os exercícios da disciplina em um único local, facilitando a leitura, os testes e futuras melhorias no código.
