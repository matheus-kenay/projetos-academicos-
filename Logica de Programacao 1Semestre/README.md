# Lógica de Programação — 1º semestre

## Sobre

Esta pasta contém seis arquivos Python identificados como PP1 a PP6. Eles reúnem exercícios desenvolvidos durante os estudos iniciais de programação.

## Arquivos

- `PP1.py`
- `PP2.py`
- `PP3.py`
- `PP4.py`
- `PP5.py`
- `PP6.py`

## Tecnologias

- Python 3
- Terminal / PowerShell para execução
- Git e GitHub para controle de versão e armazenamento do código

## Como executar

Com Python 3 instalado, abra um terminal na raiz do repositório e execute um arquivo pelo comando, por exemplo:

```powershell
python "Logica de Programacao 1Semestre/PP1.py"
```

Substitua `PP1.py` pelo arquivo que deseja testar. Alguns exercícios podem solicitar entradas no terminal.

## Objetivo da seção

Manter os códigos-fonte organizados por atividade e permitir sua consulta, execução e evolução ao longo do semestre.
